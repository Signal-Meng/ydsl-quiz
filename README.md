# 运动生理学刷题

考研运动生理学复习刷题应用:纯静态、零依赖、双击即用、完全离线。

## 使用

- **网页版**:直接双击 `index.html`(或访问 Pages 地址)。进度保存在浏览器 localStorage,可一键导出 JSON。
- **重建题库**:修改资料后运行 `python build_quiz.py`,重新解析合并生成 `data.js`。

## 功能

- 名词解释闪卡(正序 / 反序)、简答 / 论述 / 分析题背诵
- 真题模式(按年份筛选)
- 客观题快刷(从定义自动生成「定义→选术语」与挖空题,只挖真实术语)
- 错题本 / 收藏专项刷、考点章节索引
- Leitner 三盒记忆调度(不会→当天重现,模糊→次日,掌握→3/7 天后复习)
- 深色模式、移动端适配、桌面快捷键(空格翻面,1/2/3 评分,S 收藏)

## 题库构成

约 1025 张卡,由 4 个数据源解析合并去重:

| 来源 | 内容 |
|---|---|
| 考点 JSON ×2 | 两套主流教材的考点整理(含考频、题型标签) |
| 分题型背诵手册 | 名词解释 / 简答 / 论述 / 分析题拆解 |
| 真题整理 | 2014–2026 历年真题(带年份标签) |

跨来源同名术语自动合并,答案按「考试口径手册 → 真题要点 → 教材要点」排序;构建时内置文本审计,拦截转写噪声。

## 目录结构

```
├── index.html    # 入口(双击)
├── app.js        # 全部逻辑(零依赖 vanilla JS)
├── style.css
├── data.js       # 题库数据(由 build_quiz.py 生成)
├── build_quiz.py # 数据构建脚本
└── figs/         # 插图素材
```
